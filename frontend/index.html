地端 LLM 聊天 · KV Cache Analyzer

使用 llama.cpp（透過 node-llama-cpp）在本機執行的聊天介面， 展示並驗證 System Prompt 的 KV Cache 加速效果。

如何測試 KV Cache 效果：

  1. 點擊左側 Set System Prompt，貼上一段較長的 system prompt （例如數千字的角色設定或知識庫），儲存後後端會重新產生 KV cache。
  2. 開啟一個新對話並送出第一則訊息 — 因為 system prompt 已經預先被快取， 這一輪只需要運算你輸入的內容，Prefill Speed 會很快。
  3. 在同一個對話中繼續發送訊息，之前的對話歷史會留在這個對話自己的 KV cache 中不需要重算，回覆會更快開始生成。
  4. 再開一個 新對話 試試 — 因為套用了同一份 system prompt cache，一樣不需要重新評估 system prompt。
按 Enter 傳送，Shift+Enter 換行。由本機 llama.cpp 驅動。

Set System Prompt

這會更新後端儲存的 system prompt，並用它重新產生一份 KV cache 供之後所有新對話套用。目前開啟中的對話將會被重置。
